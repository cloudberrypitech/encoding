== Introduction to packages
If you have never written a python package before, please read this section for a better understanding on python packages.

=== What are packages
A package in Python is a collection of modules that are organized in a specific file format, allowing users to easily access and use its functions, classes, and commands.

=== Items Applicable with Packages
A python package has the ability to support

. Classes
. Functions
. Variables
. Modules, and
. Scripts

This can be used to create a specific command or function and acts as a base to building a package.

=== Difference between Packages and Modules
|===
|Packages |Modules

|Packages are a collection of modules.
|Modules are indivisual files containing code.

|They are top level directories and mostly contain an `__init__.py` file. *They can also contain sub-packages.*

|They can be part of a package or can stand alone. They do not require an `__init__.py` file.
|===

=== Usecases of Packages
Packages can be utilized for multiple purposes, one of which is to streamline code by providing a concise and self-contained implementation. This enables authors and publishers to document the primary code utilized in a package, allowing end-users to integrate it into a single line of code. Furthermore, packages serve as a platform for community-developed codes, enabling end-users to reuse and incorporate existing contributions into their own projects.
