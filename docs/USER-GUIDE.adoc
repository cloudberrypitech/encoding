== Desktop Installation
There are multiple methods to install the `Encodings` Module to your system. We have listed them in a tabular format below.

|===
|Installer |Compatible OS |Reliability |Installation Command

|GitHub PIP install
|Windows, Linux, and macOS
|100% - Full Compatibility with all functions.
|Run `pip install git+https://github.com/cloudberrypitech/encoding`


|Poetry Install
|Windows, Linux, and macOS
|100% - full compatibility with all functions
|Run `poetry add git+https://github.com/cloudberrypitech/encoding`

|Homebrew Tap
|Linux and macOS
|20% compatibility for Linux, 80% compatibility for macOS.
|Run `brew tap cloudberrypitech/tap` then run `brew install encoding`.

|Git Clone
|Windows, Linux and macOS
|100% - For all operating systems
|First Run `git clone --depth 1 https://github.com/cloudberrypitech/encoding` then run `pip install -e ./encoding`

|Cloudbian Terminal Install
|Cloudbian Lite Only
|50% for all Cloudbian Operating Systems, 100% for Cloudbian Lite
|Run `capt update` to update package list then run `capt install encoding`.

|Docker Container
|Windows, Linux and macOS
|100% all operating systems
|Run `docker pull encoding` then `docker run encoding`. For a specific command, type `docker run encoding <command>`.

|Wget
|Linux, macOS
|100% for macOS and Linux. 0% for Windows
|Run `curl -L -o download.zip https://api.github.com/repos/cloudberrypitech/encoding/zipball_url` then `unzip download.zip`.
|===

[NOTE]
====
If you are using macOS, use `pip3` instead of `pip`. Also note that Homebrew works only for macOS and Linux.
====

The package is updated every 1 to 5 months but depends on the basis of the priority of the package.
Note that the package also comes with a command line interface.

=== Python Installation
// Installation on Windows
To install python on a Windows system, visit the https://www.python.org/downloads[python downloads page] for a list of all available python versions. Make sure you install a python version with a release more than 3.14. After completing the GUI setup installer click on confirm to complete final installation. Type `python` in your Windows terminal to ensure that python has been successfully installed on the system.

// Installation on Linux and macOS
Python is already have the latest python release preinstalled on Ubuntu as well as other linux distros. By default, the latest linux distros include support for python 3.14 and above. Operating systems such as macOS also have python baked inside the OS, eliminating installation for python. Yet for outdated operating systems run `sudo apt update && sudo apt full-upgrade python3` or `sudo apt update && sudo apt full-upgrade python3.14` to ensure that the required release is being installed. Yet you can install any other python version which has been released after 3.14. To check whether the latest python version has been installed, type `python3 --version` to determine the exact release version. For installation of the latest python release on macOS, you can use the https://brew.sh[Homebrew] command line package manager to easily upgrade to python 3.14. To install a specific python release, type `brew install python3.x` it is suggested python 3.14 exact to be installed. If you want to upgrade python to 3.14, type `brew upgrade python3.14`.

=== Homebrew Installation
:id: header1

==== Installation on macOS
To install Homebrew on macOS, open your terminal (such as Terminal.app or iTerm2) and run the official installation script directly. Do not modify system-wide shell configurations. Run the following command:

[source,bash]
----
/bin/bash -c "\$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
----

During the process, the installer will prompt you for your Mac's user password and guide you through installing the Xcode Command Line Tools if they are missing. Once finished, follow the on-screen "Next steps" instructions to add `brew` to your `PATH`, then verify the installation by running `brew doctor` or `brew --version`.

==== Installation on Linux
Homebrew (Linuxbrew) runs in a standalone directory, requires development tools (`gcc`, `make`, `git`), and **must not be run as the root user**. 

First, install the required build dependencies based on your distribution:

* *Ubuntu / Debian:*
+
[source,bash]
----
sudo apt update && sudo apt install build-essential git curl -y
----

* *Fedora / RHEL / CentOS / Rocky Linux:*
+
[source,bash]
----
sudo dnf groupinstall "Development Tools" && sudo dnf install git curl -y
----

* *Arch Linux / Manjaro:*
+
[source,bash]
----
sudo pacman -Syu --needed base-devel git curl
----

* *openSUSE:*
+
[source,bash]
----
sudo zypper install -t pattern devel_basis && sudo zypper install git curl
----

Once the dependencies are installed, run the installer script as a **regular user**:

[source,bash]
----
/bin/bash -c "\$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
----

==== Post-Installation (Required for Linux & Apple Silicon Mac)
After the installation script completes, you **must** add Homebrew to your shell configuration so the system can find the `brew` command. Run the two commands printed in the terminal under "Next steps", which generally look like this:

[source,bash]
----
echo 'eval "\$(/home/linuxbrew/.linuxbrew/bin/brew shellenv)"' >> ~/.bashrc
eval "\$(/home/linuxbrew/.linuxbrew/bin/brew shellenv)"
----

=== Installing Advanced Package Manager(apt)
To install the `apt` package manager on macOS, you would need <<brew,Homebrew>> installed on your system. Then install the apt library from the homebrew core using `brew install apt`. Then verify the installation using `which apt` or simply `apt` in zshell terminal.

The `apt` package module is already baked into some linux distributions. 2 popular distributions with `apt` pre-installed in the package itself is Ubuntu and Debian. If you want to update apt to the latest version, then run `sudo apt update && sudo apt upgrade apt`. This command will automatically updated apt package list, as well as install the latest release of the package manager.

Advanced Package Manager *would not be able to install compatible software and might install corrupted or system incompatible ones* on other Linux distributions. Make sure to use other package managers which are specifically optimised to function on that particular distro. Note that apt was designed to run only on Ubuntu and Fedora Linux systems.
